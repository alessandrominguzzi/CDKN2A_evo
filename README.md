# CDKN2A_evo

This project aims to investigate the evolutionary history of the CDKN2A locus, with a particular focus on the origin of its dual-coding organization giving rise to p16INK4a and p14ARF. The locus will be investigated across a phylogenetically diverse set of vertebrate species through complementary approaches including comparative genomics, phylogenetics, proteomic analyses, and evolutionary modelling.
